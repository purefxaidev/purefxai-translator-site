อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก

เปิดไฟล์ → แตะ "การตั้งค่า" → เปิด "อนุญาตจากแหล่งนี้" ให้เบราว์เซอร์ → กลับมากด "ติดตั้ง"

ใส่ Gemini API key (ฟรี)

เปิดแอปครั้งแรก กด "รับ API key ฟรี" ล็อกอิน Google แล้วกด Create API key คัดลอกมาวาง กด "ทดสอบและบันทึก" — key ถูกเข้ารหัสเก็บในเครื่องเท่านั้น aistudio.google.com/apikey
